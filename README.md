## 📜 Sobre o Projeto

O **D&D Compendium** não é apenas uma landing page, é uma experiência imersiva com a temática de fantasia medieval. A aplicação permite que os usuários explorem o universo de D&D através de consultas diretas a uma API pública, além de se alistarem na guilda preenchendo um formulário inteligente. Tudo isso envelopado em um design mágico e responsivo!

## ⚔️ Funcionalidades Épicas

- **📖 O Compêndio (Integração com API):** Um grimório interativo que consome a API do *D&D 5e* para listar Magias, Monstros, Classes e Itens Mágicos. Inclui um sistema de busca com autocompletar e cache de navegação.
- **🌙 Alternância de Temas (Dark/Light Mode):** Você prefere a escuridão de uma masmorra ou a claridade de um pergaminho antigo? O site conta com um toggle de tema que salva sua preferência no `localStorage`.
- **🏰 Formulário da Guilda (ViaCEP):** Um formulário de recrutamento que utiliza a API do *ViaCEP* para preencher automaticamente os dados de endereço do usuário a partir do CEP.
- **👤 Lore do Desenvolvedor:** Uma rota exclusiva **"Saiba Mais"** (`saiba-mais.html`) com o background do criador, formatada como uma autêntica ficha de personagem.
- **📱 Design Responsivo:** Elementos flexíveis e layouts em grid/flexbox garantem que a experiência seja perfeita tanto no PC quanto no celular.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído sem o uso de frameworks complexos, focando nos fundamentos da web:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Estilização vanilla, CSS Variables, Flexbox, CSS Grid, responsividade (Media Queries) e animações baseadas no tema.
* **JavaScript (ES6):** Manipulação de DOM, consumo de APIs (Fetch API), Local Storage, e tratamento de eventos.

## 🗺️ Como Iniciar sua Jornada (Rodando o projeto)

É tão simples quanto rolar um d20! Como a aplicação é inteiramente construída em arquivos estáticos (Client-Side), não há necessidade de rodar servidores de backend.

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/leomatiazzz/dnd-compendium.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd dnd-compendium
   ```
3. Abra o arquivo `index.html` em qualquer navegador moderno.
